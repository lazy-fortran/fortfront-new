# fortfront-new

This is a production repository for the generated Lazy Fortran frontend. The
laboratory in `../lazy-fortran-new` owns research history, decisions,
experiments, runs, provenance manifests, and cross-repository wiring.

Keep this repository production-only. Do not add a local roadmap, research
ledger, model transcript, orchestration system, or copied external payload.
Use the versioned `frontend-v0` contract from the laboratory. Generated
structure and dispatch must come from schemas and StandardIR metadata; local
implementation fragments must not decide compiler-wide wiring.

General rules live in `~/code/prompts/AGENTS.md` and
`~/code/prompts/rules/fortran.md`.
